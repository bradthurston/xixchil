Flash the radio half. The board has no screen and nothing stored on it — this page writes the firmware over USB from your browser, so there is no toolchain to install.

ESP32-S3 2.4 GHz

ESP32-S3-DevKitC-1 N16R8 — 16 MB flash, 8 MB octal PSRAM.

ESP32-C5 2.4 + 5 GHz

Waveshare ESP32-C5-WIFI6-KIT-N32R8-U — 32 MB flash, 8 MB PSRAM.

Before you start

Chrome, Edge or another Chromium browser on desktop. Flashing uses the Web Serial API, which Firefox and Safari do not implement — the button will be greyed out there.

If the S3 already runs this firmware, its native USB port cannot be auto-reset by the flasher: hold BOOT and tap RESET before clicking install, or flash it over the board's UART bridge instead. The C5 goes through a CH343 bridge, so it resets normally — but Windows and macOS need the CH34x driver for it to appear at all.

After flashing

The board comes up advertising as SRC over serial and answers the app's commands. It holds nothing — pull power and it is blank, which is the design.

You still need the phone app and a crack bridge to use it end to end. Both, plus what is and is not working yet, are in the repository README and the releases.

Firmware 0.4.0-lure, built from the source in the repository. Use this on hardware you own. The images here are the same ones the build produces — webflash/README.md records the exact offsets and hashes.
